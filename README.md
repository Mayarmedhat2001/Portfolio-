# Mayar Medhat — Portfolio

Personal portfolio site: experience, side projects, skills and contact.

It's a single static page (`index.html`), no build step.

## Publish with GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`
3. The site goes live at `https://mayarmedhat2001.github.io/Portfolio-/`

## Edit

Everything lives in `index.html`. Each section (`#about`, `#experience`, `#projects`, `#skills`, `#contact`) is a plain HTML block you can edit directly.
