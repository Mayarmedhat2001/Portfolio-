Side projects

Projects that turn production lessons into code you can run

Full-stack · TypeScript · 2026 · in progress

warden live

An approval and audit layer for AI agents that take real actions. An LLM agent resolves customer-support tickets, but every tool call is checked against a role and policy engine before it runs. High-risk actions, like replying to a customer or issuing a refund, go to a human approval queue, and every decision lands in an immutable audit log.

The security boundary is the code that gates each tool call, not the prompt. A model can be talked into trying anything; it can't talk its way past a policy check.
